# Tanushree Portfolio — GitHub Pages

## Upload these files
Keep these files together in the **root** of your GitHub repository:

- `index.html`
- `style.css`
- `photo.jpg`

Do not upload the ZIP itself as the website. Download it and extract it first, then upload the three files above.

## Publish with GitHub Pages
1. Create a GitHub repository (Public is easiest for a first Pages setup).
2. Choose **Add file → Upload files** and upload `index.html`, `style.css`, and `photo.jpg` together.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. After GitHub Pages finishes publishing, open the website link shown on the Pages settings screen.

## Single-file option
A separate self-contained `index.html` is also provided. It has the CSS and profile photo embedded, so it can be uploaded by itself as the repository-root `index.html`.

## Note about project buttons
The navigation, responsive mobile menu, scrolling effects, and contact copy buttons are interactive. Resume, video, website, and Canva showcase links are placeholders until the real destination URLs are added.
